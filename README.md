# 달무티 (The Great Dalmuti)

Paper 26.3 / Java 25용 Kotlin 디스플레이 엔티티 기반 프로토타입입니다. 게임 상태는 메모리에만 보관됩니다. 표시 엔티티 생성·수정·정리, 스케줄링 및 명령은 Kolor 1.0 API를 사용합니다.

## 빌드와 설치

Gradle 9.4.1과 JDK 25가 필요합니다. 이 프로젝트는 같은 워크스페이스의 `Kolor` 폴더를 Gradle composite build로 참조합니다. 프로젝트 루트에서 `.\psychics\gradlew.bat -p .\Dalmuti build`를 실행하세요. `build`는 Kotlin으로 컴파일하고 덱, 규칙, 봇 및 라운드 진행 모델 테스트를 실행합니다.

서버에는 `Kolor-1.0.0.jar`와 `Dalmuti-1.0.0.jar`를 모두 `plugins` 폴더에 설치합니다. `paper-plugin.yml`에서 Kolor를 필수 선행 플러그인으로 선언하고 Kotlin 런타임 classpath를 공유하므로, Kolor를 먼저 설치해야 합니다. Kotlin 표준 라이브러리는 플러그인 JAR에 중복 포함하지 않습니다.

## 시작

1. 반경 6블록 이상의 평평하고 안전한 공간 중심에서 관리자가 `/dalmuti setup`을 실행합니다. 테이블 중심은 설정에 저장됩니다. 의자와 왕좌는 실제 블록을 바꾸지 않는 임시 엔티티이므로, 공중이나 위험한 지형에 설치하지 마세요.
2. 참가자는 `/dalmuti join`을 실행합니다. 관리자 포함 실제 플레이어도 먼저 참가해야 합니다.
3. 관리자가 `/dalmuti start`를 실행하면 빈 자리를 봇으로 채우고 시작합니다. `plugins/Dalmuti/config.yml`의 `participants`를 4–8로 설정할 수 있습니다. 설정은 새 대기방을 만들 때 적용됩니다.
4. 관리자가 `/dalmuti stop`으로 중단합니다. 참가자가 접속을 끊으면 모든 참가자의 게임이 중지됩니다. 종료 시 플레이어는 게임 시작 전 위치로 돌아갑니다.

`setup`, `start`, `stop`에는 `dalmuti.admin` 권한이 필요합니다(기본 OP). 하나의 서버에서 동시에 하나의 테이블만 운영합니다. Kolor의 Paper 플러그인 명령 등록을 사용하며 명령은 `/dalmuti setup|join|start|stop|revolution`입니다.

## 조작과 규칙

- 카드 정면을 바라보고 좌/우 클릭하여 개별 카드를 선택 또는 해제합니다. 자기 카드만 보이며 선택한 카드는 올라갑니다. **웅크린 채 클릭**하면 선택한 카드를 제출합니다.
- 자신의 차례에 F(보조 손 교체)로 패스합니다. 빈 테이블에서 선공은 패스할 수 없습니다.
- 같은 숫자의 카드에 광대를 섞어 낼 수 있습니다. 광대만 내면 13입니다. 선공 이후에는 정확히 같은 장수의 더 작은 숫자만 낼 수 있습니다. 나머지 참가자가 모두 연속 패스하면 마지막으로 낸 사람이 선공합니다. 그 사람이 이미 손을 비웠으면 시계 방향의 다음 참가자가 선공합니다.
- 손을 비운 순서로 다음 라운드의 좌석과 역할이 결정됩니다. 마지막 한 명은 자동으로 마지막 순위가 됩니다. 5초 뒤 다음 라운드가 시작됩니다.
- 첫 라운드에는 세금이 없습니다. 이후 대 평민은 가장 강한 카드 2장, 소 평민은 1장을 각각 대/소 달무티에게 보냅니다. 달무티는 돌려줄 카드를 선택하고 웅크린 채 클릭합니다. 봇은 약한 카드부터 돌려줍니다.
- 매 라운드 배분 직후 광대 두 장을 가진 플레이어는 `/dalmuti revolution`으로 세금을 취소할 수 있습니다. 대 평민이 선언하면 대 달무티와 자리를 바꿉니다. 광대를 가진 봇도 선언합니다. 선언 시간은 `revolution-seconds`(1–300초)로 설정합니다.
- 카드 이름은 숫자이며 숫자가 작을수록 강합니다. 상대의 손은 수량만 표시됩니다. 플레이와 세금은 테이블 위 이동 애니메이션으로 표현됩니다.

게임 중 플레이어는 제자리에 고정되며 시점은 자유롭게 움직일 수 있습니다. 카드는 눈높이에서 테이블 방향으로 배치됩니다. 임시 의자, 봇, 카드 및 애니메이션은 게임 종료와 플러그인 비활성화 시 제거됩니다.
